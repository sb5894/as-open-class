## 0단계에서 확인한 것

- `npm.cmd run build`: 화면·서버 타입 검사와 빌드 통과.
- `npm.cmd run verify:sources`: 원본 12개의 크기·SHA-256 일치.
- `npm.cmd run firebase -- --version`: 프로젝트 로컬 Firebase CLI 15.34.0 실행 확인.

- Markdown의 로컬 파일 링크 29개와 UTF-8 한글 확인.
- 개발 도구: Node 24.19.0, npm 11.17.0, Vite 8.3.4, TypeScript 7.0.2. Firebase 배포 런타임은 Node 22로 지정.

브라우저의 실제 화면 배치·터치 조작과 Android/iPhone 실기기 검사는 아직 수행하지 않았다. 이번 1단계에는 전체 화면이나 모바일 상호작용을 추가하지 않았다.

## 1단계 변경 내용

- 최초 엑셀 2개 시트를 읽고 도면 1페이지의 방 배치와 결정 기록을 대조했다. 원본 파일은 수정하지 않았다.
- 사이트 데이터 `src/data/catalog.generated.json`에 건물 3개, 관련 공간 37개, 학급/공동 그룹 30개, 공개수업 29개를 작성했다. 5-1은 비공개 공간·학급으로만 보존한다.
- 원래 학급 교실과 실제 참관 장소를 분리했다. 3-1→본관 2층 1과학실, 4-5→본관 2층 2과학실, 6-1→본관 4층 영어실, 1-3→후관 2층 1-3 교실을 반영했다.
- 6-2·6-4·6-5와 6-3의 주제를 분리했다. 다문화 3개 반, 한국어교실의 강사용 2칸 비공개, 유치원 공동 수업 1개와 가안 상태를 반영했다.
- 날짜형 학급명은 `1-1` 형식으로 정리했다. 빈 텍스트·PDF는 `null`, 렌즈 미작성은 `[]`로 유지한다. 별도 수업에 학년 공통 자료를 대체 연결하지 않는다.
- 제공된 3·4·5학년·유치원 PDF 4개의 공개용 복사본만 만들고 해당 수업에 연결했다. PDF 뷰어는 아직 구현하지 않았다.
- `scripts/convert_data.py`와 `scripts/data_rules.py`에 엑셀 변환과 도면·결정 기반 연결 규칙을 분리했다. `uv`가 openpyxl을 준비하고 스크립트 `.lock`으로 의존성을 고정한다. 같은 입력의 출력은 동일하다.
- `src/data/catalog.ts`에 타입과 공개 목록·실제 공간 수업·원래 교실에서 이동할 대상 조회를 추가했다. 미제공 텍스트를 표시할 때 공통 컴포넌트를 사용하는 `createMaterialText`도 추가했다.
- [수업 연결표](<수업 연결표.md>), [누락 자료](<누락 자료.md>), [재변환 방법](<데이터 변환.md>)을 작성했다. 자동 생성 문서는 재변환 때 함께 갱신된다.

## 남은 자료와 제한

- 1·2·6학년, 별도 수업 4개, 다문화 3개 반 지도안 미제공. 수업별 텍스트·렌즈 빈칸도 [누락 목록](<누락 자료.md>)에 기록했다.
- 빨강반 참관 문구는 문장 중간에서 끝나며, 4-3 참관 문구는 6학년 공통 문구와 같다. 원문 그대로 보존했고 작성자 확인이 필요하다.
- 유치원 공동 수업의 실제 공간, 주차·출입구는 가안이다. 행사명·날짜·주소는 확정됐고 별도 시간 항목은 표시하지 않는다.
- 6단계에서 전체 SVG와 계단·승강기·화장실의 도면상 배치를 작성했다. 실측 축척과 현장 운영·접근 경로는 별도 확인이 필요하다.
- 같은 시트명과 열 의미를 유지한 새 엑셀은 경로를 지정해 재변환할 수 있다. 학급 추가/삭제·수업실 변경·양식 변경은 추정하지 않고 규칙 검토 후 반영한다.
- 신청·Google Sheets 연결, 전체 화면, PDF 뷰어, 배포는 이번 단계에서 진행하지 않았다.
