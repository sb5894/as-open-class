검사: 타입·웹/서버 빌드, Vitest 77개, Python 데이터 변환 16개 통과. 기존 Python을 상승 실행하고 프로젝트의 openpyxl만 사용해 새 설치 없이 검증했다. 변환기 `--check`는 원본에서 29개 수업/38개 공간/3개 PDF 결과가 JSON·생성 문서와 바이트 일치함을 확인했다.

모바일 전체 실행은 Chromium/WebKit 합계 43개 통과, 외부 API 2개 생략, WebKit 수업 이동 1개 실패였다. 실패 항목은 변경하지 않은 후관 2층 첫 이동에서 발생했고 단독 재실행에서 전체 29개 수업 이동을 통과했다. 원인을 제품 오류로 단정하지 않으며 최초 실패와 재실행 결과를 구분한다. 새 6개 시나리오와 기존 나머지 시나리오는 통과했다. 실제 휴대폰 검증과 구분한다.

실제 신청/시트 행 변경은 하지 않았다. 실제 시트 헤더 세 칸 갱신 여부와 S25 실기기 PDF 확인은 기존 잔여 사항이다.

정식 배포 확인: https://as-open-class.web.app/ 와 운영 신청 함수를 갱신했다. GitHub main 코드 커밋은 `c6c87af`다. 실제 배포 자산 일치·양 엔진 화면/새 시설/유치원 이동과 복귀/기존 PDF를 확인했고, 실제 API는 유치원 ID만 포함한 불완전 입력으로 미동의 거절과 ID 허용을 확인했다. 정상 신청은 보내지 않았다. 배포 검증 스크립트는 exit 0으로 종료했다.
