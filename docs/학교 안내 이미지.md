# 학교 안내 이미지 v1 — 5단계

작성일: 2026-10-19. 위치·동선 검토용이며 배포하지 않았다. `/guide`에는 이미지를 반영했고, 모바일에서 가로 스크롤 없이 전체를 화면 폭에 맞춰 표시한다. 층별 수업 연결은 6단계다.

[원본·실제 학교·수정본 비교 페이지](reviews/school-map-v1.html)를 브라우저로 열면 번호별 대응과 가안 동선을 확인할 수 있다. 이름과 가안 표시를 각각 끄거나 ‘이미지만 보기’를 누를 수 있다. 실제 학교 이미지의 기존 빨간·파란 선은 제공된 원본의 일부다.

## 파일

| 용도 | 위치 | 크기 |
|---|---|---|
| 편집 마스터 PNG | [school-guide-v1.png](../materials/derived/maps/school-guide-v1.png) | 1024×1536, 3,006,078 bytes |
| 모바일 WebP | [768 WebP](../public/assets/maps/school-guide-v1-768.webp) | 768×1152, 245,562 bytes |
| 큰 화면 WebP | [1024 WebP](../public/assets/maps/school-guide-v1-1024.webp) | 1024×1536, 448,488 bytes |
| 웹 요소 좌표 | [overlays JSON](../src/data/school-map.json) | 왼쪽 위 기준 백분율, 가안 상태 포함 |
| 비교 검토 HTML | [검토 페이지](reviews/school-map-v1.html) | 로컬 전용. 원본을 상대 경로로 참조 |
| 정적 비교 캡처 | [PNG 캡처](reviews/school-map-v1-comparison.png) | 검토용 이름·점선 포함. 웹 배경으로 사용하지 않음 |
| 이미지 편집 프롬프트 | [prompt](../materials/derived/maps/school-guide-v1.prompt.txt) | 입력 역할·보존 조건·변경 조건 전문 |
| 인코딩 도구 | [optimize-school-map.mjs](../scripts/optimize-school-map.mjs) | `node scripts/optimize-school-map.mjs` |

내장 `image_gen` 편집 도구에 원본 PNG를 편집 대상, 주차안내 PNG를 위치 참고로 전달했다. 생성된 PNG를 별도 경로로 복사했다. 원본 3개를 포함한 전체 원본 12개의 해시는 보존 검사를 통과했다. 편집 결과는 투명 배경이며, WebP에도 알파를 유지했다. Chromium Canvas로 크기 조정·WebP quality 0.82 인코딩만 수행했다. 마스터 대비 용량은 768 버전 약 91.8%, 1024 버전 약 85.1% 감소했다. 재인코딩 결과는 Chromium 버전에 따라 바이트가 달라질 수 있다.

## 반영과 해석

- 왼쪽 세로 신관 / 가운데 가로 본관 / 위쪽 가로 후관, 연결 통로를 유지했다.
- 운동장·강당의 그림상 면적을 줄였다. 면적 비율은 실측값이 아니다. 학교숲·텃밭·놀이터와 놀이기구를 제거했다. 일반 경계 수목은 남겼다.
- 실제 안내 이미지의 흰 덮개 정구장 왼쪽 세로 구역을 태양광 주차장으로 대응시켰다. 수정본에는 태양광 지붕 아래 차량을 그렸으며 차량 수·주차 구획 수는 실제 수용량을 의미하지 않는다.
- 정구장은 기존 일러스트처럼 개방형으로 유지했다. 실제 항공 이미지의 흰 덮개는 재현하지 않았다. 건물 층수·창문·시설 외형도 현장 기록용 도면으로 해석하지 않는다.
- 건물명·버튼·클릭 영역·동선은 이미지에 없다. JSON은 6단계에서 웹 요소를 배치하기 위한 기준점이며 실제 버튼이나 확정된 클릭 다각형이 아니다. 이미지와 같은 종횡비의 컨테이너 위에 올리고 화면 크기별 터치 영역을 따로 검증해야 한다.
- 주차 동선은 아래 정문 → 정구장 오른쪽 → 정구장 위쪽 → 왼쪽 태양광 아래 주차장으로 옮겼다. 비교 페이지의 갈색 점선과 출입구 표시는 `가안`이다. 주차장→본관 보행 경로는 제공된 빨간 선에 없어 새로 확정하지 않았다.
- 비교 페이지의 좌표는 각 이미지의 화면상 상대 위치다. 항공 사진과 일러스트의 투시·비율이 다르므로 지리 좌표나 정확한 축척·북쪽 표시로 사용하지 않는다.

## 남은 확인

1. 태양광 아래 실제 주차 허용 구간·차량 수용 범위와 행사 당일 개방 여부.
2. 빨간 선에 따른 진입·회차 가능 폭, 실제 입차 지점, 출차 경로·일방통행 운영.
3. 본관 중앙 출입구 실제 개방 여부, 계단·경사로 등 접근성 및 주차 후 보행 동선.
4. 정구장 덮개를 추가로 그릴지, 운동장·강당 축소 및 숲·텃밭·놀이터 생략 후에도 현장에서 식별하기 쉬운지.
5. 6단계에서 모바일 터치 영역·건물 선택·층별 안내를 연결한 뒤 실제 기기로 확인.

이미지 제작 당시에는 프런트 화면을 변경하지 않았으며, 이후 사용자의 ‘사이트에 반영’ 요청으로 `/guide` 상단에 안내도를 연결했다. 건물명·출입구·가안 동선은 `src/components/school-map.ts`의 웹 요소로 표시하고 주차 동선을 켜고 끌 수 있다. 비교 HTML과 원본 항공 이미지는 `public` 밖에 보관한다. 6단계에서 건물·주차장 클릭과 층별 안내·전체 수업을 연결했다. [층별 안내 기록](<층별 안내.md>)을 참고한다. 배포하지 않았다.
