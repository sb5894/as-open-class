초등학교 다문화연구학교 공개수업 성과보고회용 웹사이트.
크게 두 부분으로 수정. 초대장, 참관안내.
첫 입장 시 초대장 화면으로 구성.
참관 안내로 넘어가는 버튼이 초대장에 있음.
모바일 고려 인터페이스.


1. 초대장
- 간단한 행사 소개 (일정, 장소)
- 참관신청 (지역(시 단위), 소속교, 직책?(학년이나 과목), 이름, 가장 참관하고 싶은 수업 1~2가지) < 시트 연동하여 차후 데이터 정리가 됐음 좋겠음.
- 참관 안내 리디렉션


2. 참관 안내
- 메인: 학교 전경. 대신 실제와 달리 운동장이나 놀이터 쪽은 의도적 축소하여 표현. 이미지 생성하여 표현할 예정.
- 주차장 쪽 누르면 주차 안내 나옴.
- 건물(3개) 누르면 건물 층별안내도가 나옴. 안내도 안에 교실 칸마다 학년-반과 공개수업 주제가 한줄로 써 있음.
- 교실을 누르면 학년-반과 수업 주제가 타이틀에 나옴. 그 아래에 학급·수업 맥락(학급 특징), 참관 포인트, 중점 렌즈(참여 강점 협력 표현 발견 5개 중 2~3개), 지원인력·환경 나옴 (이 데이터는 엑셀로 제공하겠음). 그 아래에 지도안 pdf(다운 없이 웹에서 바로 볼 수 있게 보임).
- 추가 요청: 참관 안내는 당일에 QR로도 배포 예정이라, 참관 안내가 메인으로 나올 링크가 나오게도 해줘야 함

+2번에 참관후 설문조사 구글폼 리디렉션 삽입 예정 (특정날짜에 작업 예정, 지시가 있을 때까지 작업하지 않음)
