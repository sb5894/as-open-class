### 둘러보기
- 주차는 운동장
#### 목록
- 신관, 후관 1층 삭제
- 특정 교실 선택한 후 돌아오면 강조표시 되는 건 좋은데, 강조표시가 다른 교실에가려질 때가 있음.
- 계단을 도면처럼 사각형에 가로줄 많이 있는 걸로 변경
- 각 층별로 교실 크기 동일하게 조정 (예: 6학년 내에서 현재 6-1만 큰데, 6학년 전체와 영어실 크기가 모두 같게 조정. 6학년만 작업하지 않고, 본관 2층 제외한  모든 층에 작업)
- 본관 2층 E/V를 계단 맞은편으로 이동
- (실제와 달라지겠지만) 다문화특별학급 모인 것을 좀 더 왼쪽으로 이동
- 다문화특별학급 빨강반 초록반 사이 강사교실 크기 동일하게
- 후관 2층 1-2 옆 계단은 1-2 옆이 아닌 엘베 옆으로 수정
- 후관 2층 본관 통로 너비 줄이기
- 교실에서 진행하지 않는 수업의 경우 도면 내 노란 사각형 학년-반 아래에 핀 이모지와 위치 표시해두기. 길이 문제로 층은 표시 X. 목록에 "3-1 과학 → 📍 본관 2층 1과학실" 같은 표기도 삭제. (예: 3-1 📍1과학실)

### 신청
- (구글 시트) 일시 표기법 수정. 날짜, 시, 분까지만 표기.
- 신청 완료 후 접수번호 보여주지 않기
- 신청이 완료되면 (구글 폼처럼) 신청 완료 페이지 보여주고, 메인 화면과 보고회 둘러보기 2가지 버튼 제공.
