# Claude 검토의 근거 확인과 반영

2026-10-16에 원본 엑셀·도면·지도안을 직접 읽어 확인했다. 원본 및 공개용 PDF의 내용과 연결 규칙은 변경하지 않았다.

| 지적 | 확인 결과와 처리 |
|---|---|
| 1. 6-2·6-3·풀잎반 북쪽 이동 | 반영하지 않음. [도면 PDF](<../materials/original/floor-plans/안성초 도면.pdf>) 1쪽의 복도 아래에 해당 세 공간이 있음. 6-2·6-3은 6-1·6-4·6-5와 같은 줄이며, 풀잎반도 샘물·햇살반과 같은 아래쪽 줄임. 북쪽에는 시청각실·6학년연구실, 유치원연구실·주방 등이 있음. 현재 south 유지 및 회귀 테스트 추가. 여기서 북/남은 도면 위/아래의 상대 위치이며 실측 방위가 아님. |
| 2. 참관 포인트 중복 | C32·C46·C48·C49가 모두 학년 시트 E12와 같음. 어떤 학년 공통 참관 문구와 일치하든 모든 학급을 보고하도록 변경. 값은 보존. 4학년 PDF 1쪽의 4-3 고유 역할 분담 문구도 작성자 확인 항목으로 기록. |
| 3. PDF 내 예외 학급 언급 | 3학년 PDF 1쪽의 3-1, 4학년 PDF 1쪽의 4-5, 5학년 PDF 2쪽의 5-1 언급을 확인. 결정 기록과 대조할 확인 항목으로 기록하며 연결 규칙 유지. |
| 4. 비고의 별도·비공개 해석 | 확인됨. 별도/비공개 비고를 대상 학급에서 제외하되, F12의 6-2·6-4·6-5는 유지. 혼합 비고·날짜형 대상 테스트 추가. 여러 주제의 실제 대상이 여전히 모호하면 변환을 중단하는 동작 유지. |
| 5. 실행 전제 조건 | 확인됨. 원본은 Git 제외이며 uv·원본 없이 변환/관련 테스트가 실패함을 데이터 변환 문서에 명시. |

유치원 주제를 PDF에서 가져오거나, 자료 구조·언어를 재설계하지 않았다. 상세 확인 항목은 [누락 자료](<누락 자료.md>)에서 함께 관리한다.
