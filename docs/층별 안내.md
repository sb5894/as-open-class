# 6단계 — 층별 안내와 전체 수업 연결

작성일: 2026-10-19. 로컬 구현·검증 결과다. Hosting·Functions 배포와 실제 신청 전송은 하지 않았다.

최신 사용자 그림에 따라 복도·가로 교실 줄을 복원했다. 건물을 누르면 여러 층을 한 페이지에 함께 표시하며 교실 칸에는 학급명, 교실 줄 바로 아래 넓은 영역에는 학년 공통 주제를 한 번 표시한다. 칸을 카드처럼 여러 줄로 접지 않는다. 가로 스크롤·층 선택은 없고, 유치원 제외에 따른 공개수업 28개·신청 선택지 13개를 유지한다. [4학년 도면 캡처](reviews/grade-4-floor-shape.png).

최신 간소화 요청을 반영해 일반실·화장실·기타 작은 네모는 표시하지 않는다. 교실·실제 수업실·계단·`E/V`만 남기며 원본 기하 기록은 보존한다. 본관·후관·신관 선택 버튼은 동일 크기로 한 행에 표시한다. 후관 2층에는 1-2와 1-3 사이에 `본관통로`를 표시하고 본관 1층은 계속 제외한다. [현재 후관 모바일 화면](reviews/rear-simplified-2026-10-19.png). 아래 원본 배치 표는 출처 대조용이며 일반실 전체를 화면에 표시한다는 뜻은 아니다.

본관 2층은 추가 요청으로 교무실·자치실을 회색 칸으로 표시한다. 자치실은 사용자가 확인한 기존 회의실 자리(교무실 왼쪽)이며 화면 이름만 변경했다. 강사용 두 교실은 글자 없는 회색 사각형이다. 계단 칸은 같은 층 E/V와 같은 높이로 줄였다. 색상 안내는 초록(공개수업 진행)·주황(다른 장소에서 공개수업 진행)·회색(공개수업 미진행) 세 항목이다. [본관 2층 최신 화면](reviews/main-2-offices-2026-10-19.png).

## 확인 경로

- `/guide`: 학교 전체 지도. 신관·본관·후관·태양광 주차장 이름이 클릭 영역이다. 학교 지도는 모바일에서도 가로 스크롤 없이 전체를 표시한다.
- `/guide/main`: 본관 4·3·2층을 함께 표시한다. 1층 제외.
- `/guide/rear`: 후관 3·2·1층을 함께 표시한다.
- `/guide/new`: 신관 3·2·1층을 함께 표시한다.
- 기존 `/guide/건물ID/층` 경로는 같은 건물 전체 화면을 표시하며 해당 층 위치로 이동한다. 더 이상 층별로 화면을 전환하지 않는다.
- `/guide/parking`: 주차 위치·진입 가안·현장 확인 항목.
- 공개수업 교실을 누르면 중간 공간 안내 박스 없이 `/lessons/수업ID?from=공간ID`로 바로 학급 안내·지도안을 연다. SVG 교실과 큰 교실 선택 버튼의 동작이 같다. 3-1·4-5·6-1의 원래 교실도 해당 수업으로 바로 연결하며 상세 상단에서 실제 수업 장소를 알린다. 상세의 돌아가기 링크는 원래 건물·층·교실로 돌아가 선택 칸만 강조한다(`?space=공간ID`). 5-1·강사용 교실은 비공개 안내만 제공한다. URL 직접 접속과 새로고침도 가능하다.

## 도면을 옮긴 기준

원본 `materials/original/floor-plans/안성초 도면.pdf`의 1페이지를 로컬 PDF.js로 PNG 렌더링하고 텍스트 좌표를 추출해 대조했다. 원본 파일은 변경하지 않았다. 전체 층을 육안 검토하고 SVG의 모든 이름표가 각 방 사각형 안에 들어오는지 별도로 검사했다.

기하·일반실·계단·엘리베이터·화장실의 기준 기록과 공통 주제 묶음 함수는 [floor-plans.ts](../src/data/floor-plans.ts)에 있다. 공개수업용 방 ID·건물·층·학급·수업은 기존 [catalog](../src/data/catalog.ts)를 그대로 조회한다. [floor-guide.ts](../src/components/floor-guide.ts)가 모든 가로 경계에 같은 투영을 적용해 건물 형태를 유지하고, 공통 주제를 도면 아래에 표시한다. 수업 내용을 기하 데이터에 복제하지 않는다.

SVG는 복도 위·아래 구분, 원래 방 순서·인접 벽·가로 교실 줄을 유지한다. 일반 공간 폭을 먼저 줄이는 도식화를 사용하며 모든 x 경계는 같은 변환을 거친다. 같은 교실 줄의 칸을 아래 줄로 접거나 재배열하지 않는다. 실측 축척은 아니다. ‘위·아래’는 제공된 도면 화면 기준이며 실제 방위를 보증하지 않는다. 이름 없는 본관 3층의 한 칸은 ‘미표기 공간’으로 보존하고 용도를 추정하지 않았다.

## 수업·비공개·자료 구분

- 초록색 방: 실제 공개수업 공간. 교실 칸 안에는 학급·짧은 방 이름을 표시한다. 공통 주제는 바로 아래에 한 번 표시한다. 6학년 6-2·6-4·6-5와 6-3은 서로 다른 주제를 각각 표시하며, 과학·영어·수석교사 수업은 별도로 표시한다. 긴 주제는 16px 본문에서 줄바꿈하고 미제공 주제는 공통 문구를 사용한다.
- 주황색 방: 원래 교실이며 실제 수업 장소가 다른 경우. 3-1→본관 2층 1과학실, 4-5→본관 2층 2과학실, 6-1→본관 4층 영어실로 이동 안내를 표시한다. 원래 교실에 해당 수업을 잘못 배정하지 않는다.
- 수석교사 1-3은 후관 2층 자기 교실에서 진행하며 불필요한 이동 안내를 넣지 않는다.
- 한국어교실은 왼쪽부터 빨강반 / 강사용 교실 1 / 강사용 교실 2 / 초록반이다. 파랑반은 본관 2층 교장실 바로 오른쪽에 있다.
- 5-1과 강사용 두 교실은 비공개 공간 안내만 표시하며 수업 상세 링크를 제공하지 않는다. 그 밖의 일반 공간은 방 이름·시설 종류만 표시한다.
- 미제공 텍스트는 공통 컴포넌트의 `자료 업로드 예정입니다.`다. 미제공 PDF는 공통 높이·회색 박스의 `자료 업로드 예정`이며 PDF 요청이나 열기·다운로드 링크를 만들지 않는다. 파일이 있는 경우의 오류·재시도·원본 열기는 기존 PDF 뷰어를 사용한다.
- 유치원은 공개수업·안내·신청 선택지에서 제외했다. 기존 지도안 공개용 복사본은 `materials/derived/excluded/kindergarten-2026-10-19.pdf`로 옮겼다. 원본과 공간·학급 기록은 보존한다. 주차 진입·중앙 출입구 가안은 유지한다.

건물별 층 도면은 위아래로 한 페이지에 모두 표시하고 가로 이동 없이 화면 폭에 맞춘다. 도면의 교실 이름은 13px, 시설 약자는 11px, 아래 주제는 16px이다. 작은 칸의 폭은 44px보다 좁을 수 있으므로 ‘교실·시설 이름 크게 보기’에 최소 44×44px의 같은 교실 선택 버튼과 계단·E/V 이름만 제공한다. SVG 링크도 키보드 선택이 가능하다. 페이지의 세로 스크롤은 사용한다.

## 검증

- `npx.cmd vitest run`: 59개 통과. 공간 배치 검증 외에 공통 주제 중복 제거·6학년 분리·별도 수업 보존·주제 묶음의 전체 28개 수업과의 일치를 검사한다. 원본 기하 기록은 10개 층·37개 공간을 보존하고 공개 안내는 9개 층이다.
- 지도에서 연결된 공개수업 ID 집합과 `getPublicLessons()`의 28개 ID 집합이 같으며, 신청서·로컬 서버가 사용하는 `interestOptions`를 풀어 얻은 ID 집합도 정확히 같다. 학년 단위 신청 선택은 개별 수업 예약으로 확장하지 않는다.
- Chromium·WebKit에서 28개 수업 각각을 실제 SVG 교실 선택→수업 상세→선택 층/공간 복귀로 확인했다. 제공된 PDF는 해당 원본 경로 요청 및 1페이지 렌더링, 없는 PDF는 공통 박스·요청 없음도 검사한다.
- Chromium·WebKit 320/390/430px에서 세 건물 모두 가로 넘침 없음·같은 교실 줄의 동일 y 좌표·주제가 SVG 아래에 위치·공통 주제 전체 표시·16px 주제 본문·큰 선택 버튼 44px·도면 글자 사각형 이탈 없음을 검사한다. 본관 1층 제외·한 건물의 모든 층 동시 존재·층 선택 없음·유치원 미노출도 검사한다.
- 전체 모바일 회귀 검사는 32개 통과·외부 API opt-in 2개 생략. Python 변환 테스트 16개와 TypeScript 단위 테스트 57개 통과. 원본 12개 크기·SHA-256 보존 확인. 타입 검사·화면/서버 빌드 통과. 변환기를 수정하고 재생성·바이트 일치 검사를 수행했다. 현재 PC에는 `uv`가 PATH에 없어 프로젝트 `.venv`에 openpyxl 3.1.5를 설치해 기존 변환기를 실행했다.

## 남은 확인과 다음 단계

실제 Android Chrome·iPhone Safari 터치·키보드·PDF 검증은 아직 하지 않았다. 계단 접근 경로·승강기 운영은 현장에서 확인해야 한다. 주차·본관 중앙 출입구는 최신 사용자 지시로 확정했다. 수업 텍스트와 지도안 미제공 항목은 기존 [누락 자료](<누락 자료.md>)를 따른다. 2026-10-19 사용자 승인으로 [모바일 검토 주소](https://as-open-class--mobile-review-mmhal97i.web.app/guide)를 배포했고 기존 신청 함수도 갱신했다. 검토 주소는 2026-10-26 23:38 KST 만료다. 실제 배포 주소에서 두 브라우저 엔진의 화면·PDF 확인과 유치원 제외·학년 선택 입력 검증을 완료했으며 새 시험 신청은 저장하지 않았다. 다음은 실기기 확인과 7단계 독립 검토다. 최종 운영 화면 배포·QR은 아직 하지 않았다.
